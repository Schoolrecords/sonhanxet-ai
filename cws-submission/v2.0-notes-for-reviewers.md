## Paste vào ô "Notes for reviewers" (English)

```
V2.0 changes from V1.6 (no new permissions, no new data collection):

1. Extended phrase generation from 1 evaluation period (End of Semester 2) to all 4 periods per Vietnamese MOET Circular 27/2020:
   - Mid-Semester 1
   - End of Semester 1
   - Mid-Semester 2
   - End of Semester 2 (unchanged from V1.6)

2. New local data file: engine/data/nhanxet-ky.json (1092 additional comment templates, loaded via the existing web_accessible_resources wildcard "engine/data/*.json" — no manifest changes needed).

3. UI: added a dropdown in the sidebar context box for teachers to select which evaluation period. Auto-detected from Vnedu's own "Học kỳ" + "Kỳ đánh giá" fields, teacher can override.

4. NO changes to:
   - permissions (still only "storage")
   - host_permissions (still *.vnedu.vn + script.google.com)
   - Data handling: still fully local. No student data ever leaves the user's browser. No new tracking, no new external APIs.
   - Single-purpose statement
   - Privacy policy

The previous V1.6 (pending review) is a strict subset of V2.0 — all V1.6 changes are included.

Tested locally with 75/75 unit tests passing (Node test runner verifies phrase pool integrity, no specific-content leakage, and engine logic for all 4 periods).
```
